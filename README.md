# SankofaClass

This is a repository for the SankofaPOWER class.

## Summer 2025

Thank you to all the participants for an amazing summer! Your work and feedback breathed so much life into this community project. 

We had 17 student contributions of data on nodes in our local food system! These GeoJSONs were uploaded to the SankofaPOWER database and are foundational as we develop the final webtool.
